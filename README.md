# Разработка приложения для работы с базой данных

## Описание проекта

Данный проект представляет собой набор функциональностей для работы с сервисом вакансий hh.ru. 
Он включает в себя функции для подключения к API и получения данных о работодателях и их вакансиях, работы с базой данных. 

Цели проекта:
1) Разработка функционала для получения данных о работодателях и их вакансиях с сайта hh.ru.
2) Реализация функций по автоматическому созданию базы данных, проектированию и созданию таблиц работодателей и вакансий.
3) Разработка функций по заполнению таблиц данными, полученными от API.
4) Создание класса для работы с базой данных DBManager, который предоставляет следующие методы:
   - get_companies_and_vacancies_count() - для получения списка всех компаний и количества вакансий у каждой из них;
   - get_all_vacancies() - для получения списка всех вакансий с указанием названия компаний, названия вакансии, зарплаты и ссылки на вакансию;
   - get_avg_salary() - для получения средней зарплаты по всем вакансиям;
   - get_vacancies_with_higher_salary() - для получения списка вакансий с зарплатой выше средней;
   - get_vacancies_with_keyword() - для получения списка вакансий по ключевому слову от пользователя.


## Установка

1. Клонируйте репозиторий по ссылке https://github.com/SuperZebrocat/HeadHunterDB

2. Установите необходимые зависимости: библиотеки psycopg2, requests

4. Точка входа находится в модуле main.py в корне проекта
